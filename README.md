# Pace Lab Crew — demo del sitio

Maqueta navegable del sitio del club de running **Pace Lab Crew** (@pacelabcrew).
Muestra las tres etapas que imagina el club: sitio con noticias, fotos y videos;
gestión de socios y cuotas con pago en línea; y tienda de merchandising.

## Ver la demo

- **Tema oscuro:** https://alejandroaguil-byte.github.io/pacelabcrew-demo/
- **Tema claro:** https://alejandroaguil-byte.github.io/pacelabcrew-demo/claro.html

Desde la versión oscura también puedes cambiar de tema con el botón **Claro / Oscuro**
del menú.

## Contenido del repositorio

| Archivo | Qué es |
|---|---|
| `index.html` | Sitio principal, fondo negro, con botón de tema |
| `claro.html` | La misma página con el tema claro activado |
| `fotos/` | Fotos de ejemplo (ver `fotos/CREDITOS.md`) |
| `LEEME.md` | Cómo editar colores, logo, fotos, precios y noticias |

## Importante

Es una **maqueta**: nombres, fotos, fechas, horarios, precios, stock y montos son de
ejemplo. No hay backend, no se envía información a ningún servidor y no se cobra nada.
Las personas de las fotos no pertenecen al club.
