# Créditos de las fotos

Todas las fotos de esta maqueta son **fotos de ejemplo** descargadas de
[Burst by Shopify](https://burst.shopify.com/), banco de imágenes de uso libre
(incluso comercial, sin obligación de dar crédito). Igual dejamos el detalle para
que el club sepa de dónde salieron y las reemplace por sus propias fotos.

Las imágenes se descargaron en distintos tamaños (900 a 2200 px de ancho) para que
el sitio cargue rápido. Los archivos se pueden reemplazar manteniendo el mismo
nombre, y el sitio seguirá funcionando.
